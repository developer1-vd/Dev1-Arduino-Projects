# App Lab import zips (AIProjects)

| Zip | App |
|---|---|
| `ArduinoClaudeStudioApp.zip` | [Claude Studio](../ArduinoClaudeStudioApp/): code the board's sketch with Claude from your browser |

On GitHub, open the zip and click **Download raw file**, then use **Import
app** in Arduino App Lab. (GitHub's green **Code → Download ZIP** zips the
whole repository, which App Lab rejects with "missing or misplaced app.yaml".)

Rebuild after changing an app: `python make_zips.py`.
