      Connect Claude
      
    Paste an Anthropic API key (sk-ant-api…, from console.anthropic.com) or a
        Claude Code token (sk-ant-oat…, made on a computer with
        claude setup-token to use your Claude subscription).
    
      
    It's stored on the board in this app's folder (.studio). Don't share or
        export the app with it in place.
