# AIProjects

Projects that use AI with Arduino.

- [ArduinoClaudeStudio](ArduinoClaudeStudio/): a local WebUI for coding Arduino with Claude Code (editor, compile/upload, serial monitor and Claude chat).

- [ArduinoClaudeStudioApp](ArduinoClaudeStudioApp/): the same idea as an App Lab app you import and run on the UNO Q / VENTUNO Q. Claude edits the app's own sketch; you flash it with Stop + Run in App Lab. Import zip in [AppLabImports](AppLabImports/).
