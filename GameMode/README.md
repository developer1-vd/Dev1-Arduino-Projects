# Game mode

Gaming on the Arduino UNO Q and VENTUNO Q.

| Folder | What |
|---|---|
| [`board-setup/`](board-setup/) | `gamemode.sh`: game mode on/off (CPU at full speed, App Lab app paused), cloud-gaming shortcuts for Fortnite and others, optional Minecraft Java launcher |
| [`ModulinoArcadeApp/`](ModulinoArcadeApp/) | App Lab app: Reaction and Simon games with Modulino Buttons + Buzzer on the LED matrix, high scores in the browser |
| [`AppLabImports/`](AppLabImports/) | Ready-to-import zip of the arcade app |
